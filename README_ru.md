# [Sky1984 Sheets Collection](https://api.github.com/repos/Ai-Vonie/Sky1984-Sheets-Collection/releases)
🌍 Читайте в: *[English](README.md) ∙* **Русский**

**Sky1984 Sheets Collection** — это обширная библиотека музыкальных листов, собранная с целью упрощения поиска нужных композиций в одном месте. Данные листы предназначены для игры на внутриигровых инструментах **Sky: Children of the Light** и использования на сайте *[Sky Music Nightly](https://sky-music-nightly.pages.dev/)*.

> ⚠️ **Внимание!**
> Данная коллекция не является полной или окончательной. Рекомендуется проверять другие источники и библиотеки на наличие обновлений, так как содержимое этого репозитория может быть устаревшим или неактуальным по сравнению с ними.

# 🔍 Как правильно искать листы

Для эффективного поиска нужной композиции старайтесь следовать этим рекомендациям:
*   **Используйте основные ключевые слова:** вводите только ключевые слова или значимую часть названия песни, а также никнейм автора.
*   **Избегайте лишнего:** исключайте из запроса **стоп-слова** (артикли, союзы, предлоги) и специфичные символы.

Поиск в репозитории работает в двух режимах:
1.  **[По названию файла](https://docs.github.com/search-github/searching-on-github/finding-files-on-github)** — нажмите клавишу `t` или кликните по кнопке (Go to file), чтобы начать поиск в меню быстрого перехода к файлу.
2.  **[По содержимому файлов](https://docs.github.com/search-github/github-code-search/using-github-code-search)** — нажмите клавишу `/` или кликните на поле поиска сверху (Type `/` to search), чтобы активировать [глобальный поиск по коду в этом репозитории](https://github.com/search?q=repo%3AAi-Vonie%2FSky1984-Sheets-Collection%20&type=code).

> ⚠️ **Внимание!**
> Для использования поиска по коду (содержимому файлов) необходимо **войти в учетную запись GitHub**.

Рекомендуется ознакомиться с документацией об [ограничениях поиска по коду](https://docs.github.com/search-github/github-code-search/about-github-code-search#limitations) и [специальном синтаксисе запросов](https://docs.github.com/search-github/github-code-search/understanding-github-code-search-syntax), чтобы понимать возможности и технические ограничения.

# 💾 Как скачать

Скачать можно как отдельные файлы, так и целые папки или весь репозиторий сразу.

### 1. Скачивание отдельного файла
Перейдите на страницу нужного файла и выберите удобный способ:
*   **Скачать файл:** Нажмите на иконку (**Download raw file**) в правом верхнем углу над кодом файла.
*   **Копировать содержимое:** Нажмите на иконку (**Copy raw file**), чтобы скопировать текст в буфер обмена.
*   **Через Raw:** Нажмите кнопку **Raw**, затем нажмите `Ctrl + S` (Windows) или `Cmd + S` (macOS), чтобы сохранить файл.

### 2. Скачивание конкретной папки
GitHub не позволяет скачивать отдельные папки стандартными средствами. Для этого используйте [Download Directory](https://github.com/download-directory/download-directory.github.io):
1.  Откройте нужную папку в этом репозитории.
2.  Скопируйте ссылку (URL) из адресной строки браузера.
3.  Перейдите на сайт [download-directory.github.io](https://download-directory.github.io/).
4.  Вставьте ссылку в поле ввода и нажмите `Enter`. Папка скачается как ZIP-архив.

### 3. Скачивание всего репозитория
Чтобы получить полную локальную копию библиотеки:
1.  Перейдите на главную страницу репозитория.
2.  Нажмите зеленую кнопку **`<> Code`**.
3.  В выпадающем меню выберите [**`Download ZIP`**](https://github.com/Ai-Vonie/Sky1984-Sheets-Collection/archive/refs/heads/master.zip).

Также можно скачать конкретную папку и весь репозиторий во вкладке [**Releases**](https://github.com/Ai-Vonie/Sky1984-Sheets-Collection/releases).

# 💭 Зачем?

Идея создать эту коллекцию была ещё два года назад, но тогда я переключился на другие игры, где также продолжал свой путь музыкального барда.

Когда появилось свободное время в FFXIV, я решил это просто сделать, так как существующие альтернативы и другие варианты библиотек меня не устраивали своей реализацией или подходом к организации, чтобы я мог эти листы использовать в других играх. Сам репозиторий был собран за пару вечеров.

### ⚙️ Технические детали
Изначально было собрано ±59 457 файлов. Финальная коллекция — это результат, где были удалены дубликаты и оставлены файлы с наиболее "качественным" внутренним содержимым и именем файла.

Для фильтрации использовался кастомный алгоритм со следующей логикой:
1.  **Полные дубликаты:** Сравнение по SHA-256 хешу файлов.
2.  **Структурные дубликаты:** Анализ JSON-содержимого метаданных.
3.  **Варианты слоев (Layer Variants):** Сравнение сигнатур нот для выявления различных вариаций раскладки одного и того же чарта.
4.  **Нечеткое сравнение (Fuzzy Matching):** Сравнение последовательностей нот внутри одной BPM-группы для выявления похожих аранжировок (с порогом сходства ~80%).

> [!NOTE]
> **Примечание:** Некоторые файлы пропускались в репозиторий, если встречались вариации песни (*Easy/Hard*, *V1/V2* и другие возможные варианты).
